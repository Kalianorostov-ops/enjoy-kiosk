# Enjoy Kiosk

Программа для планшетов на столах лаунжа Enjoy the Hookah (Ростов-на-Дону).
Показывает экран стола `https://enjoythehookah.ru/table.html?t=N&k=…` на весь экран и не даёт гостям выйти из него.

- Режим владельца устройства (полная блокировка) или закрепление экрана.
- Кнопки громкости отключены, погасший экран включается сам.
- Скрытое меню: 5 касаний в левом верхнем углу → PIN.
- Настройка стола — по QR-коду из админки.

Последняя версия: **Releases → enjoy-kiosk.apk**
(`https://github.com/<владелец>/enjoy-kiosk/releases/latest/download/enjoy-kiosk.apk`).

Сборка — автоматически в GitHub Actions при каждом изменении.
Подпись: `signing/enjoy.jks` (зашифрован), пароль — секрет `KIOSK_KEYSTORE_PASSWORD`.
